Python Fundamentals

The starting course — from no code at all to writing programs that work.

All classes
  • 12Sessions
  • 1.5 hoursEach
  • NonePrerequisite

The course to start with if you have never written a line of code. Twelve sessions build Python up from nothing — values, control flow, functions and data structures — with extra sessions for exercises and problem-solving on top of those twelve.

Almost every session comes with a practice assignment. You hand it in, you get feedback on it, and the exercises are worked through and discussed in class rather than just marked and returned.

Values and expressions

  • 01
    Variables

    Naming a value so you can use it again, and what assignment actually does.

  • 02
    Data types and type conversion

    Numbers, text and booleans — and moving between them deliberately rather than by accident.

  • 03
    Operators

    Arithmetic, comparison and logical operators, and the order Python applies them in.

  • 04
    Strings

    Working with text: indexing, slicing, formatting, and the methods you reach for daily.

Control flow

  • 05
    Conditional statements

    if, elif and else — letting a program take different paths.

  • 06
    Loops

    while and for, and recognising which one a problem is asking for.

Building real programs

  • 07
    Functions

    Packaging a piece of work under a name, with arguments and a return value.

  • 08
    Exception handling

    try and except — dealing with what goes wrong instead of crashing.

  • 09
    Collections

    Lists, tuples, sets and dictionaries, and picking the right one for the job.

🚀 Next course Python Intermediate NumPy and Pandas, object-oriented Python, scraping the web, and Streamlit.

These are the main 9 topics, not the whole of it — the exercise sessions go wherever the group needs them. Questions are welcome, get in touch.
